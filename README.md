# Beneful Industry Research Presentation (BUS 102 / FYIC, Unit 2)

- `Beneful_Industry_Research.pptx`: the editable deck (12 slides, red and white, fade/push transitions, speaker notes on every slide)
- `Beneful_Industry_Research.pdf`: a PDF preview. Re-export it from PowerPoint after you add your headshot.
- `src/build_deck.js`: the script that generates the deck

## Before you submit
1. Slide 1: click the picture icon in the circle and insert your headshot.
2. Check the name and date on slides 1 and 11.
3. File → Export → PDF and upload that to Canvas.
